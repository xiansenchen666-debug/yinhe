银河量化智能跟单使用教程

🔒 资金安全说明

银河系统 仅获取交易权限，不会触碰用户资金。所有资金始终保留在 用户自己的交易所账户 中，无需转入平台，使用更安心。

🚀 当前支持的功能

  • ✅ 场外跟单功能（已上线，可直接使用）
  • 🚀 银河官方量化策略（初版即将推出，具体以官网信息为准）

🧭 只需 4 步，快速开启智能跟单

  1. 打开 银河量化官网教程页
  2. 申请并绑定 API-Key
  3. 选择想要跟随的 交易员
  4. 配置参数后 启动跟单

币安（电脑）

📌 Key 类型说明（重要）

在同一账户下，存在两种不同类型的 API-Key（功能与权限不同，不能互用）：

  • 合约交易 API-Key：仅用于 在银河系统中进行智能跟单。
  • 带单账户 API-Key：用于 在银河系统中进行跟单，同时 具备带单功能。

请务必区分用途并妥善保存。

  1. 登录 币安官网或 PC 客户端，鼠标移到用户头像，点击下拉菜单中的 账户。
  2. 在左侧选择 API 管理，取消勾选此框。
  3. 点击右上角 创建API。
  4. 选择 系统生成，点击 下一步。
  5. 随意填写一个名称，点击 下一步。
  6. 记录 API 密钥 和 密钥，妥善保存，然后点击 编辑权限。
  7. 勾选启用 允许合约 权限，点击 保存。**保存后“密钥”将不再可见，请务必提前复制保存。**
  8. 进入 合约交易页面 → 点击右上角 设置按钮 → 在 仓位模式 中打开 双向持仓 功能。

币安（手机）

  1. 打开 币安 App，在“首页”左侧点击 设置按钮。
  2. 点击 更多服务。
  3. 在上方搜索框输入 API，进入 API 管理。
  4. 先取消勾选此框，然后点击 创建 API。
  5. 选择 系统生成，点击 下一步。
  6. 填写名称，点击 下一步。
  7. 在列表中找到刚创建的 API，记下 API 密钥 和 密钥，点击 编辑。
  8. 勾选启用 允许合约，上滑回到顶部，点击 保存。
  9. 进入 合约交易页面 → 点击右上角 三个点 → **偏好设置** → 在 仓位模式 中打开 双向持仓 功能。

欧易 OKX（电脑）

  1. 登录 OKX 官网/PC 客户端，鼠标移到用户头像，在下拉菜单中点击 API。
  2. 点击 创建 API key。
  3. 备注名 随意；用途选择 API 交易；权限勾选 交易。
  4. 设置并记录一个复杂度足够高的 密码短语（或密码），点击 提交全部。
  5. 在弹窗中点击 显示信息，记录 API key、密钥 以及 密码短语。
  6. 进入 合约交易页面 → 点击右上角 设置按钮 → 在 仓位模式 中打开 双向持仓 功能。

欧易 OKX（手机）

  1. 登录 OKX App，点击左上角 九宫格。
  2. 滑动到底部，点击 API。
  3. 点击 创建 API key。
  4. 填写 备注名；用途选择 API 交易；权限点亮 交易；创建并记录 密码短语。
  5. 在“一创建的 API”弹窗中点击 显示详情，记录 API key、Secret key 以及 密码短语。
  6. 进入 合约交易页面 → 点击右上角 三个点 → 交易设置 → 在 仓位模式 中打开 双向持仓 功能。

芝麻开门（电脑）

📌 提示

新注册的 Gate.io 账户需先手动交易任意一笔，以创建合约账户。

  1. 登录 Gate.io 官网，鼠标移到用户头像，点击下拉菜单中的 API 管理。
  2. 点击 创建 API Key。
  3. 填写 备注名；启用 永续合约 的读写权限；钱包、返佣明细、Account 设置为只读权限。
  4. 记录 Key、Secret 并妥善保存。
  5. 进入 合约交易页面 → 点击右上角 三个点 → 交易设置 → 在 持仓模式 中打开 双向持仓 功能。

芝麻开门（手机）

  1. 登录 Gate.io App，点击上方 搜索框。
  2. 搜索框输入 API，点击 API。
  3. 点击 创建 API Key。
  4. 填写 备注名；启用 永续合约 的读写权限；钱包、返佣明细、Account 设为只读。
  5. 复制 Key、Secret 并妥善保存。
  6. 进入 合约交易页面 → 点击右上角 三个点 → 交易设置 → 交易配置 → 持仓模式 中打开 双向持仓 功能。

Bitget（电脑）

  1. 登录 Bitget 官网/PC 客户端，鼠标移到用户头像，点击下拉菜单中的 API 密钥。
  2. 点击右侧 新建 API Key。
  3. 选择 系统生成的 API 密钥。
  4. 输入 备注名、API 口令，配置权限，点击 下一步。
  5. 复制 API Key 和 SecretKey，妥善保存。
  6. 进入 合约交易页面 → 点击右上角 设置按钮 → 在 持仓模式 中打开 双向持仓 功能。

Bitget（手机）

  1. 打开 Bitget App，点击上方 搜索框。
  2. 在搜索框中输入 API，选择 API 密钥。
  3. 点击 新建 API Key。
  4. 选择 系统生成的 API Key。
  5. 输入 备注名、口令，并按图示设置权限。
  6. 记录生成的 API Key 和 密钥，妥善保存。
  7. 进入 合约交易页面 → 点击右上角 三个点 → 交易设置 → 在 持仓模式 中打开 双向持仓 功能。

如何开始跟单

  1. 进入 银河量化控制台 → 点击 账户管理，点击 编辑 API-Key。
  2. 选择交易所，填写之前创建的 API Key 和 Secret，可在此处设置或修改杠杆，填写完成后点击 确定。
  3. 等待约 10 秒，系统会为该账户分配专属跟单服务器，并且自动激活账户。

🔥 两种跟单方式

方式一：交易员广场

点击左侧 智能跟单 → 交易员广场，可选择银河量化平台上线的交易员。

  • 无论带单员是 公开持仓 还是 隐藏持仓，均可实现 无延迟跟单。

方式二：自选跟单

点击左侧 智能跟单 → 自选跟单，可自行选择 币安、欧易、Gate.io、Bitget 等平台的带单员进行跟单。

  • 在 币安平台：
    • 若带单员为 隐藏持仓，开仓会有约 2 分钟延迟，但平仓 无延迟。
    • 若带单员为 公开持仓，开仓和平仓均为 无延迟。
  • 在 币Coin 平台：
    • 市场行情波动较大时，可能会出现 不稳定情况。

跟单系统配置指南

本文档旨在帮助您理解并正确配置跟单系统的各项参数，以实现最佳的跟单效果并有效控制风险。

1. 资金管理模式

目前提供三种资金管理模式，请根据您的需求选择：

固定金额
  • 定义：即永远以用户设置的金额去计算下单数量。
  • 举例：如用户设置固定金额 1000U 跟单，则无论实际本金有多少，或者跟单产生盈亏多少，最终都是以 1000U 计算下单数量。
全仓模式
  • 定义：即使用合约账户全仓本金计算下单数量。
  • 机制：本金减少后，之后计算的下单数量也会相应减少。
  • 注意：强烈建议不要同时对多个交易员使用全仓模式，因为资金共用会显著增加爆仓风险。
滚仓模式
  • 定义：与交易所跟单模式一致，可理解为分配独立资金给此交易员。
  • 机制：分配一定资金后，随着交易员的盈利或亏损，该额度会动态变化。当资金小于等于 0 后，即不再触发跟单。

2. 基础设置

  • 跟单倍率：
    • 这是您与交易员仓位比例的乘数。
    • 设置为 1：表示与交易员保持完全一致的仓位比例（例如交易员开 10%，您也开 10%）。
    • 设置为 0.5：表示只跟随交易员一半的仓位比例（降低风险）。
    • 设置为 2：表示放大两倍跟随（高风险高收益）。
    • 建议：新手建议从 0.5 或 1 开始，切勿盲目放大倍率。

3. 启动跟单设置

决定在您点击“启动跟单”的一瞬间，如何处理交易员当前已经持有的仓位：

  • 不复制（默认/推荐）：
    • 系统只跟随交易员未来新开的订单，不处理当前已有的旧仓位。
    • 优点：风险最小，入场点位清晰。
  • 仅复制浮亏持仓：
    • 如果交易员当前有被套（浮亏）的单子，您会立即按当前价格买入。
    • 优点：您的入场成本可能比交易员更低，适合博反弹。
  • 复制所有持仓：
    • 立即按比例复制交易员当前账户内的所有持仓，无论盈亏。

4. 持仓方向限制

  • 无限制：跟随交易员的所有操作（开多、开空）。
  • 只开多单 / 只开空单：
    • 适用场景：当您对大趋势有明确判断（例如牛市只做多），或者只信任交易员的某个方向能力时使用。

5. 开仓与加仓触发条件

系统允许您针对开仓（第一笔单）和加仓（后续补单）分别设置不同的跟随策略，以控制成本和滑点。

5.1 价格优于交易员的百分比

  • 定义：配合“限价”模式使用的一个参数。
  • 作用：设置一个百分比（如 1%），表示只有当市场价格比交易员的参考价格优惠 1% 时，系统才挂单进场。
  • 计算逻辑：
    • 做多：挂单买入价 = 参考价 × (1 - 1%)。
    • 做空：挂单卖出价 = 参考价 × (1 + 1%)。
  • 优点：获得比交易员更好的入场成本（例如他买在 100，您买在 99）。

5.2 触发模式选项（适用于开仓与加仓）

1. 市价（默认）
  • 行为：交易员下单后，系统立即以当前市场对手价成交，不参考“价格优于交易员的百分比”。
  • 优点：保证跟单成功率，几乎不会漏单。
2. 持仓均价限价
  • 行为：系统挂单价格参考交易员的持仓均价（即成本价）。
    • 如果是开仓：持仓均价即为第一笔成交价。
    • 如果是加仓：持仓均价为加权平均后的总成本价。
  • 优点：严格控制入场价格，完全避免滑点，确保您的综合持仓成本始终优于或等于交易员。
3. 加仓价限价（即“当前成交价限价”）
  • 行为：系统挂单价格参考交易员当前这一笔操作的成交价。
  • 优点：只关注当前这一笔单子的入场点位，不考虑之前的持仓成本，灵活性更高。

6. 止盈止损（核心风控）

  • 持仓止盈 / 持仓止损：
    • 触发价格：设置具体的止盈/止损价格或比例（如亏损 10% 平仓）。
    • 循环触发：平仓后如果条件再次满足，是否允许再次开仓。
    • 平仓数量：通常设置为 100%，即触发后全部平仓。
  • 跟单亏损阈值（重要）：
    • 设置一个金额（如 100 USDT）或百分比。
    • 当您跟随该交易员的累计亏损（包含浮亏）达到此数值时，系统会自动暂停跟单并平仓所有该交易员的持仓。
    • 作用：这是您的“熔断机制”，防止单个交易员爆仓拖累您的整个账户。
  • 安全垫亏损值：
    • 设置一个保护垫（如 0 表示不启用）。
    • 当账户净值跌破预设值时，系统会自动降低跟单倍率，防止亏损进一步扩大。

7. 币种黑名单

  • 只跟单的币种：白名单模式，只跟特定的币（如 BTC, ETH）。
  • 不跟单的币种：黑名单模式，过滤掉高风险的山寨币。

8. 通知设置

  • 通知方式：推荐绑定 TG机器人 或 邮件。
  • 通知类型：下单成功/失败、触发风控、止盈止损等。

9. 高级风控设置

这些设置用于应对极端情况或交易员的异常行为，进一步保护您的资金安全。

9.1 交易员本金监控

  • 触发条件：当交易员账户的净值低于您设定的本金值（如 100 USDT）时触发。
  • 风控响应：推荐选择“停止跟单并平仓”，立即停止跟随并清空所有持仓，规避归零风险。

9.2 交易员持仓超大杠杆监测

  • 触发条件：交易员持仓杠杆倍数超过阈值（如 60倍）。
  • 风控响应：建议选择“降低跟单倍率并跳过本单”或“仅跟平”。

9.3 用户持仓超大杠杆监测

  • 触发条件：您的跟单持仓总价值 / 您的跟单账户实际本金。
  • 风控响应：一旦触发，建议立即执行“降低跟单倍率”或“停止跟单”。

9.4 异常高频交易风控（防刷单）

  • 检测机制：检测时间窗口内（如 60秒）操作次数过多。
  • 风控响应：跳过本单或暂停跟单。

⚠️ 风险提示

跟单交易存在风险，过往业绩不代表未来表现。请务必根据您的风险承受能力，合理设置 跟单倍率 和 跟单亏损阈值。
