## 1. 使用步骤详解
### 第一步：进入官网教程页  
[https://galaxyquantitative.com/tutorial](https://galaxyquantitative.com/tutorial)  

### 第二步：点击左侧「申请 API-KEY」  
根据页面指引，申请你所使用交易所的 API-KEY。  

📌 **温馨提示：币安与 Bitget 的 API-Key 区别说明**  
在 **币安（Binance）** 和 **Bitget** 交易所中，同一账户下存在 **两种不同类型的 API-Key（功能与权限不同，不能互用）**：  

- **合约交易 API-Key**：仅用于 **在银河系统中进行智能跟单**，不具备 **在交易所的带单功能**。  
- **带单账户 API-Key**：同样用于 **在银河系统中进行跟单**，同时 **具备交易所的带单功能**，在下单时交易所会同步执行带单操作，让他人实时跟随。  

绑定到银河时：  
- **普通跟单用户** → 使用「合约交易 API-Key」  
- **带单用户（想带他人跟单）」** → 使用「带单账户 API-Key」  

请务必区分用途并妥善保存，两类 API-Key 权限独立、不可互用。  

### 第三步：点击左侧「使用银河量化跟单」  
根据页面指引完成 API 绑定。  

### 第四步：查看详细参数教程  
如果需要更详细的跟单参数教程，请查看推文《银河跟单参数设置》。

> - 自选跟单：自选各平台带单员进行跟单（部分平台/场景在行情剧烈时可能不稳定）。

## 跟单系统配置指南

本文档融合了《跟单系统配置指南》完整内容，覆盖更细的参数与风控解释。

### 1. 资金管理模式
* **固定金额**  
  - **定义**：始终以用户设置的固定金额计算下单数量。  
  - *举例*：设置 1000U 跟单，则无论本金与盈亏如何变化，都按 1000U 计算下单。
* **全仓模式**  
  - **定义**：使用合约账户**全仓本金**计算下单数量。  
  - *机制*：本金减少后，后续计算的下单数量也会相应减少。  
  - *注意*：**强烈建议不要同时对多个交易员使用全仓模式**，资金共用会显著增加爆仓风险。
* **滚仓模式**  
  - **定义**：与交易所跟单模式一致，可理解为为该交易员**分配独立资金**。  
  - *机制*：分配额度随盈亏动态变化；当资金≤0 后，不再触发跟单。

### 2. 基础设置
* **跟单倍率**  
  - 定义：您与交易员仓位比例的乘数。  
  - **1**：与交易员保持相同仓位比例；**0.5**：一半仓位（更稳健）；**2**：放大跟随（更高风险）。  
  - *建议*：新手从 `0.5` 或 `1` 开始，避免盲目放大。

### 3. 启动跟单设置
决定点击「启动跟单」时，如何处理交易员已有仓位：  
* **不复制**（默认/推荐）：只跟随**未来新开**订单；风险最小、入场清晰。  
* **仅复制浮亏持仓**：若交易员被套，则按当前价买入，可能获得更低成本，适合博反弹。  
* **复制所有持仓**：立即按比例复制其当前账户所有持仓（无论盈亏）。

### 4. 持仓方向限制
* **无限制**：跟随交易员所有开平方向。  
* **只开多单 / 只开空单**：在趋势判断明确时使用（如牛市只做多）。

### 5. 开仓与加仓触发条件
系统允许为**开仓**与**加仓**分别设置策略，控制成本与滑点。

#### 5.1 价格优于交易员的百分比
* **定义**：配合“限价”模式的百分比参数。  
* **作用**：仅当市场价格相对交易员参考价更优惠（如 `1%`）时才挂单。  
* **计算**：做多=参考价×(1-百分比)；做空=参考价×(1+百分比)。  
* **优点**：获取优于交易员的入场成本。

#### 5.2 触发模式选项（开仓与加仓适用）
1. **市价（默认）**：立即以对手价成交，不参考上面的百分比；成功率最高。  
2. **持仓均价限价**：参考交易员**持仓均价**挂单，严格控价，综合成本优于或等于交易员。  
3. **加仓价限价（当前成交价限价）**：参考**当前这一笔**操作的成交价，更灵活，不考虑历史成本。

### 6. 止盈止损（核心风控）
即使交易员不止损，您也可强制自保：  
* **持仓止盈/止损**：设置触发价（或比例）、是否循环触发、平仓数量（常用 `100%`）。  
* **跟单亏损阈值（重要）**：当跟随该交易员的**累计亏损（含浮亏）**达到设置金额/比例时，**自动暂停跟单并清空该交易员持仓**，相当于“熔断”。  
* **安全垫亏损值**：净值跌破阈值时，**自动降低跟单倍率**，防止亏损扩大。

### 7. 币种黑名单
* **只跟单的币种**：白名单模式，只跟特定币（如 BTC、ETH）。  
* **不跟单的币种**：黑名单模式，过滤高风险山寨币。  
  - *操作*：选择“不跟单的币种”，在输入框填入币种，多币用逗号分隔（如 `DOGE,SHIB,PEPE`）。

### 8. 通知设置
建议开启通知，及时掌握账号动态：  
* **通知方式**：推荐绑定 **TG 机器人** 或 **邮件**。  
* **通知类型**：下单成功/失败、触发风控、止盈止损等。

### 9. 高级风控设置
用于极端行情或异常行为的保护：

#### 9.1 交易员本金监控
* **触发**：交易员账户**净值**（含未实现盈亏）低于设定本金（如 `100 USDT`）。  
* **响应**：仅通知 / 降低跟单倍率 / 暂停跟单 / **停止并平仓（推荐）**。

#### 9.2 交易员持仓超大杠杆监测
* **触发**：  
  - **总持仓杠杆倍数**=交易员所有持仓总价值 / 实际本金 > 阈值（如 `60`）。  
  - **单币持仓杠杆倍数**超过阈值。  
* **响应**：**降低跟单倍率并跳过本单** 或 **仅跟平**。

#### 9.3 用户持仓超大杠杆监测
* **触发**：您的**跟单持仓总价值 / 跟单账户实际本金**超过阈值。  
* **响应**：**降低跟单倍率**或**停止跟单**，防止杠杆失控。

#### 9.4 异常高频交易风控（防刷单）
* **检测**：在设定窗口（如 `60秒`）内操作次数超过限值（区分开/加仓与平/减仓）。  
* **响应**：**跳过本单**或**暂停跟单**，避免因异常频繁操作造成手续费损耗。

## 风险提示
