平台使用教程

第一步：在交易所创建并获取 API Key

登录您的交易所账户，进入 API 管理页面，新建 API，并仅勾选“读取权限”和“现货/合约交易权限”。请勿开启提现权限，这是标准的安全配置。

第二步：在控制台绑定 API

进入银河量化控制台，点击“添加交易所 API”，选择交易所类型后粘贴 Key 与 Secret。平台使用加密存储方案，避免明文暴露。

第三步：选择交易员并设置风控

根据收益曲线、回撤表现、胜率与交易频率选择适合您的交易员，同时设置单笔仓位、最大回撤、止损阈值，确认后即可启动跟单。

第四步：持续监控与优化

建议您每日查看控制台中的最近信号、收益波动和策略表现。若账户规模扩大，可升级订阅计划或开通额外账户席位，实现多账户分仓跟单。

开通前检查清单

确认交易所账户正常
确保账户已完成身份验证，并具备可用资金。
确认 API 权限正确
只保留读取和交易权限，关闭提现权限。
确认网络环境稳定
避免本地频繁切换网络，以便及时完成风控确认与通知接收。
确认风险承受能力
根据自身资金规模设置跟单金额和最大亏损上限。

常见问题

绑定 API 后可以提现吗？

不能。平台只建议您开启读取和交易权限，提现权限始终保持关闭状态，因此平台无法转出您的资产。

可以同时跟多个交易员吗？

可以。如果您需要多策略并行，可通过额外账户席位或多个子账户实现分仓运行。

新手适合选择什么套餐？

建议从月付或季付开始，熟悉整套跟单流程后，再根据收益目标升级半年或年度旗舰版。
