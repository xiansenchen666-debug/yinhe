银河量化完整使用教程

我已经基于您 `教程` 文件夹中的文档内容重新整理了教程页，把原来的简版说明升级为官网版完整教程。现在这个页面不仅告诉用户怎么开通，还把 API 获取、跨平台绑定、参数配置、风险控制和常见问题都整合进来了。

银河系统仅获取交易权限，不接触用户资金；所有资金始终保留在用户自己的交易所账户中。平台支持币安、欧易、Gate.io、Bitget 等主流交易所跨平台跟单。

教程总览

支持功能
场外跟单已上线，银河官方量化策略也将逐步开放。
核心优势
不限制人数、不设最低门槛、不抽取利润分成，用户收益尽量完整保留。
适用对象
新手可按四步快速上手，专业用户可进一步配置风控、倍率和跟单触发规则。
四步开通流程
01

申请 API Key

进入您使用的交易所 API 管理页面，创建新的 API Key，仅开启读取和交易权限，不开启提现权限。

02

绑定银河账户

进入银河量化控制台，添加交易所 API，填写 Key、Secret 以及交易所要求的密码短语等信息。

03

选择交易员

可以在交易员广场选择平台已上线的交易员，也可以在自选跟单中选择外部公开带单员。

04

配置参数并启动

设置跟单倍率、资金管理模式、止盈止损和风控阈值后，启动跟单并持续观察表现。

交易所 API 指引

币安 Binance

  • 支持电脑端和手机端创建 API。
  • 普通跟单用户使用“合约交易 API-Key”。
  • 带单用户使用“带单账户 API-Key”，两类 Key 不可混用。
  • 创建完成后，务必开启合约权限，并在仓位模式中打开双向持仓。

欧易 OKX

  • 创建 API 时用途选择“API 交易”，权限勾选“交易”。
  • 除 API Key 和 Secret 外，还必须妥善保存密码短语。
  • 进入合约页面后，同样需要打开双向持仓模式。

Gate.io 芝麻开门

  • 新注册账号需先手动交易一笔，创建合约账户后再申请 API。
  • 永续合约设置为读写，钱包、返佣、Account 建议只读。
  • 跟单前建议再次确认持仓模式是否为双向持仓。

Bitget

  • 同样存在普通跟单 Key 与带单账户 Key 的区别，请按用途区分。
  • 创建 API 后需记录 API Key、SecretKey 和口令。
  • 在交易设置里完成持仓模式与权限复核后，再进入银河绑定。
参数配置指南
重点说明： 根据您 `跟单系统配置指南_v2.md` 的内容，我把最核心、最影响收益与风险的参数浓缩成了下表。用户可以先看这里建立完整认知，再进入控制台逐项配置。
配置模块 说明 建议
资金管理模式 支持固定金额、全仓跟单、复利滚动三种模式。固定金额最稳定，全仓模式最激进，复利模式更接近真实滚仓。 新手优先选择固定金额或低倍率复利滚动。
跟单倍率 决定您跟随交易员仓位比例的大小，倍率越高，收益和风险都被同步放大。 建议从 `0.5` 或 `1` 开始，不建议一上来放大到 2 倍以上。
启动跟单模式 可选择不复制旧仓、仅复制浮亏持仓或复制所有持仓。不同模式决定您启动时是否跟入交易员现有仓位。 默认推荐“不复制”，逻辑更清晰，风险更可控。
开仓/加仓触发 支持市价、持仓均价限价、加仓价限价，还可设置价格优于交易员的百分比触发。 追求成交成功率用市价，追求成本控制再用限价。
止盈止损与亏损阈值 可设置持仓止盈、持仓止损、跟单亏损阈值和安全垫亏损值，超限后自动减仓、暂停或停止跟单。 强烈建议每个交易员都配置止损与总亏损阈值。
高级风控 支持异常高频交易、交易员本金监控、交易员持仓超大杠杆、用户持仓超大杠杆等监测场景。 建议至少启用“仅通知”或“暂停跟单并平仓”级别的响应。
开通前检查清单

账户状态正常

确认交易所账户完成实名，账户中有可用资金，并已开通合约相关功能。

权限配置正确

API 只保留读取和交易权限，严禁开启提现权限。

仓位模式正确

按照教程要求，把合约账户的仓位模式切换到双向持仓。

风控逻辑清晰

先设定单交易员跟单资金、最大亏损、倍率和止损条件，再启动策略。

常见问题

绑定 API 后平台能提现吗？

不能。银河系统只需要读取和交易权限，不接触用户资产，资金始终保留在用户自己的交易所账户中。

可以同时绑定多个交易所或多个账户吗？

可以。您可以通过额外账户席位支持多平台、多子账户运行，适合做资金分散和策略隔离。

公开持仓和隐藏持仓跟单有区别吗？

有。根据您教程资料中的说明，部分平台对隐藏持仓会存在开仓延迟，而公开持仓通常能实现更低延迟甚至无延迟跟单。

新手第一次应该怎么配置？

建议从固定金额、小倍率、不复制旧仓开始，先运行 1 到 2 周观察策略风格，再逐步升级到更高阶的配置方案。
